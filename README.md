## 1. Supabase

프로젝트 키는 이미 `supabase.js` 와 `overlay/index.html` 두 곳에 들어 있습니다.
프로젝트를 새로 만들 때만 두 파일의 URL·anon 키를 교체하세요.

### 순서를 지켜야 합니다

1. **Authentication → Users → Add user** 로 관리자 계정 생성
   (이메일 · 비밀번호, **Auto Confirm User 켜기**)
2. **SQL Editor** 에 `supabase_setup.sql` 붙여넣고 Run

반대로 하면 쓰기 권한이 `authenticated` 로 잠긴 상태에서 계정이 없어
본인도 관리자에서 저장할 수 없습니다.

권한은 브라우저가 아니라 DB(RLS)에서 나뉩니다.

| 동작 | 누가 |
|---|---|
| 읽기 (사이트 표시) | 누구나 |
| 등록 · 수정 · 삭제 | 로그인한 관리자만 |
| 문의 보내기 | 누구나 |
| 문의 열람 | 관리자만 |

## 2. GitHub → Cloudflare Pages

1. 폴더 구조 그대로 새 저장소에 업로드
2. Cloudflare Pages → Connect to Git → 저장소 선택
3. 빌드 설정은 비웁니다 (Framework preset = None, 빌드 명령 없음)
4. Deploy

### `.github` 폴더 주의

드래그앤드롭으로는 점으로 시작하는 폴더가 만들어지지 않습니다.
GitHub 웹에서 **Add file → Create new file** 을 누르고 파일 이름 칸에
`.github/workflows/keepalive.yml` 을 그대로 입력한 뒤 내용을 붙여넣으세요.

이 워크플로는 월·목에 Supabase 를 한 번씩 호출해 무료 프로젝트가
일시정지되는 것을 막습니다. 저장소 **Settings → Secrets → Actions** 에
`SUPABASE_URL` 과 `SUPABASE_ANON_KEY` 를 등록해야 동작합니다.

재배포는 바뀐 파일을 덮어쓰고 Commit → 1~2분 → `Ctrl+Shift+R`.

## 3. SOOP 게시글에 넣기

게시글에는 **페이지 주소를 그대로** 넣습니다.

```html
<iframe height="3200" scrolling="no" src="배포주소"
        style="width:100%;border:0;display:block;"></iframe>
```

높이는 폭에 따라 달라집니다. 한 값만 적어야 하면 **큰 쪽**을 고르세요.
여백이 남는 편이 스크롤바가 두 개 생기는 것보다 낫습니다.

| 페이지 | 1240px | 1000px | 780px | 420px |
|---|---|---|---|---|
| 프로필 (`/`) | 2500 | 2700 | 3200 | 4400 |
| 방송 일정 | 1500 | 1600 | 1850 | 2400 |
| 노래책 | 1300 | 1400 | 1900 | 2600 |
| 업보 | 1200 | 1300 | 1600 | 2300 |
| 옷장 | 1600 | 1750 | 2100 | 3000 |
| 미니게임 | 1350 | 1400 | 1600 | 2000 |

### 하지 말 것

- **중첩 iframe** — 숲 앱이 게시글 재로딩으로 처리해 무한 새로고침이 납니다
- **자동 리다이렉트** (`location.replace`) — 같은 이유
- 높이 `postMessage` — 숲은 듣지 않습니다

## 4. 관리자

`배포주소/admin/` 으로 접속, Supabase 에 만든 계정으로 로그인합니다.
비밀번호는 코드 어디에도 없습니다. 변경 · 분실 · 관리자 추가는
Supabase → Authentication → Users 에서 처리합니다.

탭은 값이 **어느 화면에 나오는지** 기준으로 갈려 있습니다.

| 탭 | 내용 |
|---|---|
| 🖼 이미지 | 히어로 배경 · 프사 · 로딩 얼굴 · SUNROOM 사진 · 갤러리 4 · 대표곡 · VOD |
| 🏠 메인 상단 | 이름 · 영문 라벨 · 소개 2줄 · 배지 · 한마디 · NEXT LIVE · 스탯 6칸 값 |
| 🏷 라벨 | 스탯 라벨 6 · 프로필 라벨 4 · 갤러리 캡션 3 · LIVE 배지 · 푸터 워드마크 |
| 🎀 프로필 카드 | 프로필 표 · 태그 · SUNROOM 라벨과 소개문 · LIKE / DISLIKE |
| 📆 이번 주 | 섹션 제목 · 안내문 · 방송 요일 · 요일 7칸(이름·내용·시간) · 일정 3줄 |
| ♪ 대표곡·링크 | 대표곡 제목·설명·링크 · 푸터 링크 버튼 4 |
| 📅 일정 | 달력에 들어갈 일정 (기간 일정은 종료일 입력) |
| 🎵 노래 | 노래책 목록 · ARCHIVE 영상 |

| 👗 옷장 | 옷 등록 (새 옷 / 기존 옷) |

## 5. 이미지 넣는 법

이미지는 저장소에 올리지 않고 **주소만** 넣습니다.

SOOP 비공개 게시판에 사진을 올린 뒤 사진 위에서 우클릭 → **이미지 주소 복사**.
글 주소(`.../post/...`)가 아니라 `https://stimg.sooplive.com/...` 형태여야 합니다.
관리자 입력칸 아래 미리보기가 뜨면 정상, 빨간 안내가 뜨면 주소가 잘못된 것입니다.

| 칸 | 비율 | 권장 크기 |
|---|---|---|
| 히어로 배경 | 2.5:1 | 1560×620 |
| 프로필 사진 | 1:1 | 400×400 |
| 로딩 화면 얼굴 | 1:1 | 320×320 |
| 갤러리 1~4 | 3:4 | 900×1200 |
| 옷장 | 3:4 | 900×1200 |

프로필 사진은 SOOP 아이디만 넣으면 자동으로 가져옵니다.

## 6-2. 미니게임

`game/` 폴더에 네 가지가 들어 있습니다.

| 게임 | 내용 |
|---|---|
| 사다리타기 | 가로줄은 숨긴 채 캐릭터를 눌러 타고 내려갑니다. 2~10명 |
| 제비뽑기 | 컵에서 막대를 뽑습니다. 제비 2~12개, 당첨 개수 지정 |
| 핀볼 | 이름표를 단 구슬이 코스를 굴러 결승선을 끊는 순서가 결과 |
| 원판 룰렛 | 돌림판. **항목은 페이지에서 바로 고칩니다** (관리자 아님) |

### 핀볼 — lazygyu Marble Roulette 이식

원본 저장소(MIT, (c) 2023 LazyGyu)의 `src/data/maps.ts` 를 `game/maps.js` 로
**좌표 그대로** 옮겼습니다. 라이선스 전문은 `game/LICENSE-lazygyu-roulette.txt`.
물리는 Box2D 대신 같은 월드 단위의 원-선분 충돌로 다시 구현했고 원본 상수를 그대로 씁니다 —
중력 10, 구슬 반지름 0.25, 쿨타임 `1000 + (1 - weight) * 4000`, 끼임 감지 5초.

- 맵 4종 — 운명의 수레바퀴 · 거품 터뜨리기 · 욕망의 항아리 · 밤을 달리다
- 이름 문법 — `이름*3` 구슬 3개(확률 3배), `이름/2` 스킬을 자주 씀
- 1등 · 꼴등 · N등 / 속도 아주 느리게·느리게·보통·2배 / 스킬 토글
- 결승선 5칸 안에서 확대 + 슬로모션, 미니맵, 실시간 순위

**터지는 오브젝트(`life:1`)는 반드시 유지해야 합니다.** 거품 터뜨리기 14개,
밤을 달리다 217개가 닿으면 사라지는 거품인데, 빼면 골 입구가 막혀 아무도 완주하지 못합니다.

회전하는 막대는 접점 속도(`v = ω × r`)를 구슬에 전달해야 합니다. 이걸 빼면 구슬이
막대 위에서 균형을 잡고 영원히 내려오지 않습니다(욕망의 항아리에서 전원 미완주).

출발 슬롯 자체는 맵마다 유불리가 있어(자리별 카이제곱 795~1200) **이름을 슬롯에 무작위로
배분**합니다. 자리 편향이 사람에게 붙지 않으므로 이름별 확률은 균등합니다.

공정성 실측 — 각 맵 240판, 6명, 1등이 누구인지:

| 맵 | 이름별 1등 | 카이제곱 (기준 11.07) | 판정 |
|---|---|---|---|
| 운명의 수레바퀴 | 38 41 50 36 39 36 | 3.45 | PASS |
| 거품 터뜨리기 | 36 47 46 38 34 39 | 3.55 | PASS |
| 욕망의 항아리 | 43 39 40 39 39 31 | 2.06 | PASS |
| 밤을 달리다 | 34 44 39 46 36 41 | 2.65 | PASS |

### 원판 룰렛

항목은 원판 오른쪽 목록에서 바로 고칩니다. 칸에 적으면 원판에 즉시 반영되고
브라우저에 저장돼 새로고침해도 남습니다. 2~12칸.
칸 수마다 12,000회씩 20번 돌려 카이제곱 평균이 자유도와 일치하는 것을 확인했습니다.

## 7. 연출 바꾸기

`fx.js` 맨 위 네 줄만 고치면 됩니다.

```js
var FX_FLOAT = ['🍋','✦','🌿','✧','🍋','✦'];  // 떠다니는 입자
var FX_CLICK = '🍋';                          // 클릭 · 프사 톡
var FX_COUNT = 16;                            // 입자 개수
var FX_TILT  = true;                          // 카드 기울기
var FX_LOADER_IMG = 'assets/loader.jpg';      // 로딩 화면 원형 얼굴 (관리자 🖼 이미지 탭에서도 교체 가능)
```
